# 단어장 앱 기획 문서

> 작성일: 2026-06-09
> 문서 버전: v0.1 (초안)
> 상태: 기획 단계 — 개발 착수 전 검토용

---

## 1. 개요

### 1.1 한 줄 소개
예문 중심으로 단어를 쉽게 익히고, 주기적인 알람으로 복습을 유도하며, TTS·사전 연동으로 발음까지 들을 수 있는 **클라우드 공유 단어장 앱**.

### 1.2 핵심 가치
| 가치 | 설명 |
|------|------|
| **이해하기 쉬운 학습** | 단어를 단독이 아니라 예문·맥락과 함께 제시 |
| **잊지 않게 하는 복습** | 망각 곡선 기반 알람/푸시로 주기적 리마인드 |
| **들으면서 익히기** | TTS 기본 발음 + 네이버·구글 사전 연동 |
| **어디서나 같은 단어장** | 클라우드 동기화 + 타인과 공유·협업 |

### 1.3 타깃 사용자
- 영어/외국어 단어를 꾸준히 외우고 싶은 학습자
- 여러 기기(폰·태블릿)에서 동일한 단어장을 쓰고 싶은 사용자
- 친구·스터디·강사-수강생 간에 단어장을 공유하려는 그룹

## 2. 기술 방향 (확정 사항)

기획 회의에서 결정된 핵심 방향:

| 항목 | 결정 | 비고 |
|------|------|------|
| **플랫폼** | 모바일 앱 (iOS + Android) | 크로스플랫폼 단일 코드베이스 권장 |
| **공유 범위** | 개인 기기 간 동기화 **+** 타인 공유 둘 다 | 계정/권한 관리 필요 |
| **발음 기능** | 기기/클라우드 **TTS 우선** + 네이버·구글 사전 **연동** | 안정적·합법적 접근 |

### 2.1 권장 기술 스택 (제안)
> 최종 확정은 개발 착수 시 별도 논의

- **클라이언트(앱)**: Flutter (단일 코드로 iOS/Android, 알람·로컬 알림 플러그인 성숙)
  - 대안: React Native
- **백엔드/클라우드**: Supabase (확정)
  - Auth(로그인), Postgres + RLS(단어장 데이터·기기 간 동기화), Edge Functions(서버 로직), pg_cron(예약 발송)
  - 대안: Firebase (NoSQL/FCM 선호 시) — 비교는 `기술스택비교.md` 참고
- **TTS**:
  - 기본: 기기 내장 TTS (`flutter_tts`) — 오프라인·무료
  - 고품질 옵션: 클라우드 TTS(Google Cloud TTS 등) — 자연스러운 음성
- **사전 연동**: 네이버/구글 사전 **딥링크** 방식 (앱에서 해당 단어 페이지로 이동)

## 3. 핵심 기능 명세

### 3.1 단어 관리
- 단어 등록: 단어 / 뜻 / 품사 / 발음기호(선택)
- **예문**: 단어당 1개 이상의 예문 + 예문 해석 (핵심 학습 단위)
- 태그/카테고리: 토익, 일상회화, 시험 D-7 등 자유 분류
- 즐겨찾기·중요 표시
- 외운 정도(학습 상태): 미학습 / 학습중 / 완료

### 3.2 학습 / 복습 모드 ★핵심
복습은 단어를 단독으로 외우는 방식이 아니라 **예문과 함께 단어를 보고 맞추는 방식**을 기본으로 한다.
- **예문 보고 단어 맞추기 (직접 입력)** ★MVP 우선: 예문·해석·품사를 보고 단어를 직접 입력 (첫 글자/글자 수 힌트 제공)
- **예문 빈칸 채우기 (객관식)**: 단어가 빠진 예문 + 한글 해석을 제시하고, 4개 보기 중 알맞은 단어를 고름
- 정답 확인 시 예문 전체·발음(TTS)·사전 링크를 함께 노출해 맥락으로 학습
- 학습 진행률·통계 (오늘 외운 개수, 누적, 정답률)

#### 복습 섞기 비율 (Review Mix) ★신규
- **이미 외운(학습완료) 단어를 복습 세트에 다시 섞어 출제**하는 비율을 사용자가 슬라이더로 조정 (0~100%)
- 예: 비율 20% → 한 세트 15문제 중 3문제는 과거에 맞췄던 단어로 구성
- 장기 기억 강화 목적. 0%면 신규/예정 복습만, 높을수록 과거 단어 재등장 빈도 증가
- 과거 단어 선택은 학습완료 이후 경과 시간·정답률을 가중해 우선 출제 (오래된·약한 단어 우선)

### 3.3 알람 / 복습 알림 ★핵심
- **주기적 알람**: 사용자가 지정한 시간/간격에 복습 푸시
  - 예: 매일 오전 9시 / 3시간마다 / 점심·저녁 2회
- **망각 곡선 기반 복습(SRS)**: 1일 → 3일 → 7일 → 30일 간격 자동 재노출
  - 간격 반복(Spaced Repetition) 알고리즘 적용
  - 위 **복습 섞기 비율**에 따라 학습완료 단어를 추가로 혼합
- 푸시 알림 클릭 → 바로 예문 복습 화면으로 진입
- 알림 내용에 단어+뜻 미리보기 (잠금화면에서도 학습)
- 조용한 시간(방해 금지 시간대) 설정

### 3.4 발음 듣기 ★핵심
- **TTS 재생**: 단어·예문을 음성으로 (영국식/미국식 선택)
- 카드·목록·알림 등 어디서나 스피커 아이콘으로 즉시 재생
- **사전 연동 버튼**: 네이버 사전 / 구글 번역에서 원어민 발음·추가 예문 확인 (딥링크)
- (향후) 발음 따라 말하기·녹음 비교 기능 검토

### 3.5 클라우드 동기화 & 공유 ★핵심
- **로그인**: 이메일 / 소셜 로그인(구글·애플)
- **개인 동기화**: 동일 계정으로 여러 기기에서 실시간 동기화
- **타인 공유**:
  - 단어장 단위 공유 (읽기 전용 / 함께 편집 권한)
  - 공유 링크 또는 초대 코드
  - 공개 단어장 둘러보기·복제(향후)
- 오프라인 지원: 네트워크 없을 때도 학습, 연결 시 자동 동기화

### 3.6 단어 정리 — 그룹 관리 · 인라인 수정 · 스와이프 삭제 ★신규

단어가 많아질수록 "찾기·정리·고치기"가 중요해진다. 단어장 상세 화면에서 단어를 빠르게 분류하고, 뜻을 즉시 고치고, 손쉽게 지울 수 있게 한다.

#### (1) 그룹별 관리
- **그룹(소분류)**: 한 단어장 안에서 단어를 다시 묶는 단위. 예) "토익 단어장" 안에 `Day 1`, `Day 2`, `Part 5 빈출`, `안 외워지는 단어`.
- 단어는 그룹을 **0개 또는 1개** 가질 수 있다(미지정 단어는 "그룹 없음"으로 모임). *(향후 다중 그룹/태그 확장 검토)*
- 단어장 상세 화면:
  - 상단에 **그룹 필터 칩**(전체 / 그룹별)으로 보기 전환
  - 그룹별 **섹션 헤더 + 접기/펼치기**(헤더에 그룹명·단어 수 표시)
  - 단어를 다른 그룹으로 **이동**(개별·다중 선택), 그룹 **생성·이름변경·삭제**
- **그룹 생성 진입점**(필수): 단어장 상세 화면 상단의 **"그룹 추가" 버튼**(앱바 액션)으로 **빈 그룹을 먼저 만들 수 있다.** 단어가 한 개도 없어도 그룹은 단어장에 저장·표시된다.
  - 보조 경로: 단어 "그룹 이동" 시트의 **"새 그룹 만들기"**로도 즉석 생성 가능.
- 그룹은 **단어장에 소속·저장**되며(단어 유무와 무관하게 유지), 헤더에서 **이름 변경·삭제·정렬**할 수 있다.
- 그룹 삭제 시 소속 단어는 삭제되지 않고 "그룹 없음"으로 이동(단어와 그룹의 수명 분리).

#### (2) 뜻 인라인 수정
- 단어 목록·상세에서 **뜻을 바로 수정**할 수 있게 한다(전체 편집 화면 진입 없이).
- 동작: 뜻 텍스트를 **탭(또는 길게 눌러 "뜻 수정")** → 인라인 입력 필드로 전환 → 수정 후 **완료/포커스 아웃 시 즉시 저장**.
- 빈 뜻으로 저장 불가(기존 값 유지 + 안내). 저장 시 `updatedAt` 갱신, 클라우드면 동기화.
- *(확장)* 동일 인라인 방식으로 단어/품사/발음기호도 편집 가능하도록 일관 적용 검토.

#### (3) 스와이프 삭제 (왼쪽 슬라이드 → 임계점 통과 시 자동 삭제)
단어 항목을 **왼쪽으로 슬라이드**해서 삭제하는 제스처. iOS의 "끝까지 밀어 삭제"와 유사하되, **임계점(threshold)을 넘기면 색이 바뀌고 그 상태에서 손을 떼면 자동 삭제**되도록 한다.

- **단계별 동작**
  1. 항목을 왼쪽으로 끌면 뒤에서 **삭제 배경**이 드러난다(휴지통 아이콘 + "삭제" 라벨).
  2. **임계점 미만**: 배경은 중립색(회색). 손을 떼면 항목이 **원위치로 복귀**(삭제 안 함).
  3. **임계점 이상**(예: 항목 너비의 **65%** 이상 이동): 배경색이 **삭제 경고색**으로 전환되고(시각/햅틱 피드백), "놓으면 삭제됩니다" 상태로 바뀐다.
  4. **경고색 상태에서 손을 떼면**: 확인 다이얼로그 없이 **자동 삭제**.
- **임계점 미만에서 멈춰 떼면**: 부분적으로 열린 상태에서 노출된 **삭제 버튼을 눌러야** 삭제(누르면 한 번 더 확인). → "확인 후 삭제" 경로.
- **안전장치(필수)**: 자동 삭제 직후 **하단 스낵바에 "실행취소(Undo)"**를 수 초간 노출. Undo 시 원래 위치·그룹 그대로 복원. (자동 삭제 UX의 핵심 보호장치)
- **모노크롬 정책과의 조화**: 앱 전반은 모노크롬이지만, **삭제 같은 파괴적 액션의 경고색만 예외**로 절제된 빨강을 허용할지 여부는 디자인 결정 사항으로 둔다(Open Issue 참고). 미허용 시 진한 잉크색 + 아이콘 강조로 대체.
- **임계점·민감도**(예: 65%), 애니메이션 곡선, 햅틱 시점은 사용성 테스트로 조정.

## 4. 화면 구성 (정보 구조)

```
[로그인 / 회원가입]
       │
   [홈 / 대시보드]  ── 오늘의 복습, 학습 통계, 빠른 시작
       │
   ├─ [내 단어장 목록]
   │      └─ [단어장 상세] ── 그룹 필터·섹션, 뜻 인라인 수정, 왼쪽 스와이프 삭제
   │             └─ [단어 카드 상세] (뜻·예문·발음·사전링크)
   │
   ├─ [학습하기] ── 플래시카드 / 퀴즈 / 예문 모드
   │
   ├─ [공유 / 탐색] ── 공유받은 단어장, 공개 단어장
   │
   └─ [설정] ── 알람·복습 주기, TTS 음성, 계정, 방해금지 시간
```

## 5. 데이터 모델 (초안)

```
User
 ├─ id, email, displayName, photoUrl
 └─ settings (알람주기, TTS음성, 방해금지시간대, reviewMixRatio[복습섞기비율 0~100])

Wordbook (단어장)
 ├─ id, ownerId, title, description, tags[]
 ├─ groups[] (그룹명 목록, 정렬 순서 = 화면 표시 순서)  ★신규
 ├─ visibility (private | shared | public)
 └─ members[] (userId, role: owner|editor|viewer)
 # 그룹은 단어장에 소속·저장된다. 빈 그룹도 유지되며 그룹명이 곧 키 역할.
 # 그룹 삭제 = groups[]에서 제거 + 소속 Word.group 을 '' 로 이동(단어는 보존).

Word (단어)
 ├─ id, wordbookId, group(그룹명, '' = 그룹 없음), term, meaning, partOfSpeech, phonetic  ★group 추가
 ├─ examples[] (sentence, translation)
 ├─ favorite (bool)
 └─ srs (학습상태, 다음복습일, 복습단계)
 # 뜻(meaning) 등은 인라인 수정 지원, 수정 시 updatedAt 갱신
 # (확장 시) 그룹을 별도 WordGroup 엔터티(id·order)로 정규화 검토

StudyLog (학습 기록)
 └─ userId, wordId, result, studiedAt
```

## 6. 개발 우선순위 (단계별 로드맵)

### MVP (1단계) — 최소 기능 제품
- 단어/예문 CRUD, 단어장 관리
- **예문 보고 단어 직접 입력 복습 모드** (첫 글자·글자 수 힌트 포함)
- 기기 TTS 발음
- 로그인 + 개인 클라우드 동기화
- 기본 알람(지정 시간 푸시)

### 2단계
- 망각 곡선 기반 복습(SRS) 알림
- **예문 빈칸 채우기(객관식) 모드 + 복습 섞기 비율 슬라이더**
- **단어 그룹(소분류) 관리 + 뜻 인라인 수정 + 왼쪽 스와이프 삭제(임계점 자동 삭제 + Undo)**
- 네이버·구글 사전 딥링크 연동
- 학습 통계·진행률

### 3단계
- 단어장 타인 공유·공동 편집
- 공개 단어장 탐색·복제
- 고품질 클라우드 TTS 옵션
- (검토) 발음 녹음·비교, 위젯, 다국어
